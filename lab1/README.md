# Cache Project

Проект реализует кэширование чисел Фибоначчи с двумя стратегиями: LRU и LFU.

## Функциональность

- **Fibonacci** - вычисление чисел Фибоначчи с кэшированием
- **LRU Cache** - стратегия "Least Recently Used" 
- **LFU Cache** - стратегия "Least Frequently Used"
