# Лабораторная работа 0: Парсер

## Описание
Программа для анализа текстовых файлов и подсчета частоты встречаемости слов. Поддерживает русский и английский языки.

## Функциональность
-  Подсчет частоты слов в тексте
-  Поддержка кириллицы и латиницы  
-  Сортировка результатов по убыванию частоты
-  Экспорт в CSV формат

## Использование
```bash
g++ -o parser src/lab0_parser.cpp
parser input.txt output.csv
