#  ЛАБ_0. Парсер

##  Описание проекта

Программа для анализа текстовых файлов и подсчета статистики встречаемости слов. Поддерживает обработку русских и английских текстов, предоставляет экспорт результатов в CSV формате.

## Функциональность

### Основные возможности:
-  **Подсчет частоты слов** - точная статистика по всем словам в тексте
-  **Поддержка языков** - русский и английский языки
-  **Сортировка результатов** - по убыванию частоты встречаемости
-  **Экспорт в CSV** - сохранение результатов в формате CSV
-  **Обработка больших файлов** - работа с объемными текстами

## Использование
```bash
text_parser input.txt output.csv
