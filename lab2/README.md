# Space Invaders Clone



Игра в жанре Space Invaders на C++ с использованием SFML.



## Особенности



- Два типа врагов: обычные и сильные

- Механика "красной линии" опасности

- Шанс мгновенной смерти от числа 666

### Сборка

mkdir build

cd build

cmake ..
